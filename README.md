## Задание 2: Автотесты для API

### Автотесты для проверки программы, которая помогает заказать бургер в Stellar Burgers

### Реализованные сценарии

Созданы API тесты покрывающие эндпоинты:

- `Создание пользователя`
- `Логин пользователя`
- `Удаление пользователя`
- `Создание заказа`



### Структура проекта

- `methods` - пакет, содержащий методы тестов
- `request_data` - пакет, содержащий текстовые данные тестов
- `tests` - пакет, содержащий тесты, разделенные по классам `TestRegestrationUser`, `TestOrderUser`

### Запуск автотестов

**Установка зависимостей**

> `$ pip install -r requirements.txt`

**Запуск автотестов**

> `$ python -m pytest -v -s`

**Сгенерировать отчет**

> `$ allure serve allure_results`
